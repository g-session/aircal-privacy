隐私政策

简体中文 / English

Nexus株式会社（以下简称「本公司」）就所提供服务中用户个人信息的处理，特制定如下隐私政策。

个人信息的处理

第1条　个人信息的定义

「个人信息」指个人信息保护法所称之「个人信息」，包括可以通过姓名、出生日期、地址、电话号码、邮箱地址等记载识别特定个人的信息，以及容貌、指纹、声纹相关数据，健康保险证的被保险人号码等。

第2条　个人信息的收集方式

本公司通过以下方式收集个人信息。

  1. 1.注册时提供的信息：姓名、出生日期、地址、电话号码、邮箱地址等。
  2. 2.服务使用时的信息：操作记录、使用状况、上传的文件。
  3. 3.设备信息：IP地址、浏览器类型、设备信息。
  4. 4.位置信息：使用App时取得的位置数据。
  5. 5.第三方社交媒体服务：通过Google、Facebook、Twitter、LinkedIn等提供的信息（以下简称「第三方社交媒体服务」）。

第3条　个人信息的使用目的

本公司将个人信息用于下列目的。

  1. 1.服务的提供与运营
  2. 2.用户认证与身份确认
  3. 3.提供客户支持
  4. 4.分析使用状况与改进服务
  5. 5.开发新功能与新服务
  6. 6.确保安全与防止滥用
  7. 7.计算付费服务的使用费用
  8. 8.遵守法律法规
  9. 9.利用位置信息优化服务
  10. 10.通过第三方社交媒体服务提供联动功能
  11. 11.其他与上述目的相关的事项

第4条　个人信息使用目的的变更

本公司仅在合理认为变更后的使用目的与变更前具有相关性时，方会变更个人信息的使用目的。如有变更，本公司将依指定方式通知用户。

第5条　向第三方提供个人信息

除下列情形外，本公司未经事先同意不会向第三方提供个人信息。

  1. 1.依据法律法规
  2. 2.为保护个人生命、身体或财产所必需
  3. 3.为改善公共卫生或推进儿童健全成长所特别必要
  4. 4.需要配合国家机关或地方公共团体等

本公司可能会向业务委托方及合作伙伴（云服务供应商、分析服务供应商等）共享个人信息。在此情况下，会签订适当合约，彻底执行信息保护。

来自第三方社交媒体服务的信息

本公司允许用户通过以下第三方社交媒体服务创建账号并登录使用本服务。

  • Google

当用户通过第三方社交媒体服务进行注册，或以其他方式授权本公司访问该服务时，本公司可能会收集已与用户第三方社交媒体账号关联的个人数据，例如姓名、邮箱地址、活动记录、与该账号关联的通讯录等。

用户也可能可通过第三方社交媒体账号选择与本公司分享其他信息。用户于注册时或通过其他方式选择提供此类信息及个人数据时，即视为允许本公司依本隐私政策使用、共享、储存这些信息。

数据保护与安全管理

第6条　数据保护

本公司为保护个人信息实施下列措施。

  1. 1.数据加密
  2. 2.利用安全基础设施
  3. 3.限制访问权限
  4. 4.定期安全审计
  5. 5.制定数据泄露应对流程

第7条　个人信息主体的权利

用户享有下列权利。

  1. 1.请求披露个人信息
  2. 2.要求更正或删除
  3. 3.要求停止使用
  4. 4.数据可携权
  5. 5.撤回同意的权利

本公司将对上述权利的行使迅速且真诚地予以回应。

本服务特有的处理

第8条　本服务特有的处理

  1. 1.日历、日程、账号与设置

为了显示、创建、编辑、发送通知及同步日历和日程，本公司会处理您设备上的日历信息，以及通过 Google Calendar API 获取和更新的 Google 日历信息。若您连接了 Google 等外部日历，相关信息也会依照各服务提供商的隐私政策进行管理。

为了进行账号身份验证、同步个人资料和 App 设置、提供共享日历功能以及保存日程模板，本公司使用 Firebase Authentication 和 Firestore。根据您使用的功能，本公司会保存个人资料设置、设备信息、与共享有关的信息，以及日程模板的标题、地点、备注、重复和通知设置等。

为了提供关联和共享功能，本公司会将 Google 关联所需的身份验证凭据（访问令牌和刷新令牌）存储在由本公司管理的 Firebase 中。本公司不会获取或存储您的 Google 账号密码。

  1. 2.AI 日程创建、图像分析与颜色建议

使用 AI 创建和分析日程时，本公司会使用您输入或提供的文本和图像，将其转换为日程候选。

使用语音输入时，设备的语音识别功能会将语音转换为文本。为了创建和分析日程，转换后的文本可能会发送至 Apple Private Cloud Compute，或经 Firebase Cloud Functions 发送至 Google Gemini。语音识别的处理方式取决于设备和操作系统的功能及设置。

您直接输入的文本和为创建日程而提供的图像，也会由 Apple Private Cloud Compute 处理，或经 Firebase Cloud Functions 由 Google Gemini 处理。实际使用哪种处理服务取决于设备是否支持等因素，简单文本可能会在设备上处理。

在支持的设备和操作系统版本上，日程颜色建议通常会在设备上处理。可用功能和处理方式因设备、操作系统及设置而异。

  1. 3.付费功能购买与使用资格

为了验证和恢复购买并管理付费功能的使用资格，本公司会使用 RevenueCat，并向其发送用户标识符、购买信息等。

  1. 4.邀请链接与来源归因

为了创建共享日历的邀请链接、传递邀请信息及衡量用户来源，本公司使用 Firebase Cloud Functions 和 AppsFlyer。生成邀请链接时，会向 AppsFlyer 发送邀请者的显示名称、日历名称、日历 ID 和邀请令牌等信息。为了将用户来源与 App 用户关联，本公司也会向 AppsFlyer 发送已登录用户的标识符。根据设置，相关处理还可能涉及设备信息、标识符、IP 地址，以及安装和链接使用情况等信息。

  1. 5.提醒与推送通知

为了提供日程提醒、共享日历更新通知和待办事项通知，本公司会使用设备上的日程信息、通知设置和通知令牌。通知通过 Firebase Cloud Messaging (FCM) 或 Apple Push Notification service (APNs) 发送。共享通知可能包含日程标题、日期和时间、日历名称、显示名称及待办事项名称等。

  1. 6.使用情况、错误、性能、配置下发与滥用防范

为了分析服务使用情况、调查错误、测量性能、下发 App 配置及防止滥用，本公司使用 Firebase Analytics、Crashlytics、Performance Monitoring、Remote Config 和 App Check。根据 App 启动和功能使用情况、设置、同意情况及设备环境，本公司会向各项服务发送用户标识符、交互事件、App 和设备信息、错误、性能信息，以及用于验证 App 完整性所需的信息等。

  1. 7.广告

为了展示广告、管理同意及衡量广告效果，本公司使用 Google AdMob。广告标识符及类似信息会根据您的同意、设备设置、App 设置和使用环境进行处理。广告及同意管理也受 Google AdMob 服务提供商的政策约束。

您可以在设备设置中更改使用广告标识符的权限。付费版会停止显示广告。

  1. 8.地点搜索

使用地点搜索时，本公司会将您输入的搜索词、语言，以及必要时根据您当前位置确定的搜索范围发送至 Google Places API，以获取地点建议和详情。所获取的信息用于输入和显示日程地点。

  1. 9.URL 预览与咨询

使用 URL 预览时，设备会访问相应 URL，以获取网页标题、描述和图像等元数据，从而显示预览。所访问网站的政策也适用。

从相应来源获取显示公告、帮助内容、个人资料图片及类似内容所需的信息时，也会发生通信；相关来源会收到 IP 地址等通信信息。

提交咨询时，为了回复并调查问题，本公司会将消息正文、回复邮箱地址、回复偏好设置、已登录用户的标识符、App 和设备信息、语言设置、Pro 状态、诊断信息、附件图片等发送至 Firebase。实际发送的项目会根据您提供的内容和使用环境而有所不同。

第9条　AI与自动化

本公司使用AI技术改进服务，但不会将用户的个人数据用于其他AI模型的训练。同时，对AI处理内容保持透明。

第10条　数据删除

用户删除账号或单独请求删除数据时，按以下流程处理。

  1. 1.用户数据的删除：立即删除
  2. 2.缓存数据的删除：30天内删除

第11条　数据保留期限

本公司在提供服务所必需的期间或法律规定的期间内保留个人信息。超过保留期限的数据将依适当方式销毁。

第12条　跨境数据传输

本公司可能在日本境外的服务器处理个人信息。届时将遵循欧盟通用数据保护条例（GDPR）及其他国际数据保护标准，并适用标准合同条款（SCC），采取保护措施。

第13条　未成年人使用

本服务如为未成年人使用，须取得监护人同意。未成年人请在取得监护人同意后使用本服务。

第14条　数据泄露通知

若发生个人信息泄露，将迅速通知用户并采取以下应对。

  1. 1.调查受影响情况
  2. 2.联络相关用户
  3. 3.实施防止再发生的措施
